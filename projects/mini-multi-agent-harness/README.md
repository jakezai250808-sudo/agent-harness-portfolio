# mini-multi-agent-harness

Goal: build a minimal, runnable Agent Harness demo that shows how multiple agents coordinate on engineering work.

## v0.1 Scope

- planner / executor / reviewer roles;
- task ownership;
- memory/history preflight;
- tool call log;
- PASS/BLOCK report;
- fake-green detector;
- recovery note when context is stale.

## Interview Value

This project supports Agent Harness interviews by showing that agent reliability is a system design problem, not just a prompt-design problem.
